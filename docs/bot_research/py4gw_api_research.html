01Executive Summary

  • Py4GW is a Python 3.13 (32-bit) framework that interfaces with the Guild Wars 1 client via a DLL injection layer (Py4GW.dll), exposing game memory structures as Python classes. Latest release: v3.0 (December 2025). HIGH
  • The framework provides a comprehensive API covering 37+ modules: Agent management, Inventory, Skillbar, Map navigation, Party control, Effects, Pathfinding (A* + NavMesh), and a full FSM/Coroutine system for bot state management. HIGH
  • The BottingClass is the high-level orchestrator with 18 subclasses (Move, Wait, States, Templates, Events, Multibox, Party, Player, SkillBar, Items, Merchant, Dialogs, Interact, Map, Properties, UI, Target, Quest) that encapsulate all bot operations. HIGH
  • Movement uses a dual system: FollowXY for waypoint-based movement and FollowAutoPath for A*-based pathfinding with NavMesh, Chaikin smoothing, and LOS optimization. HIGH
  • Asterius the Mighty in Varajar Fells is farmable with E/A Shadow Form + Sliver Armor builds at approximately 8 kills/hour. Drop rate for Asterius' Scythe is extremely low (green drop standard). Heroes must be flagged outside radar range to prevent item assignment to NPCs. MEDIUM

Coroutine / Yield Patterns

Py4GW uses Python generators (yield) for cooperative multitasking. The three main paradigms:

1. Yield-Based Bot (Recommended)

# Each bot step is a generator that yields control back
def my_step():
    yield from Yield.wait(1000)              # Wait 1 second
    yield from Yield.FollowPath(path_points)  # Follow path
    yield from Yield.CastSkillID(123, target) # Cast skill

# Register with FSM
bot.States.AddCustomState(my_step, "Farm Step")

2. Sequential Bot (Simpler but Blocking)

# Uses blocking Sequential routines (polling loops + sleep)
Sequential.FollowPath(path_points)
Sequential.CastSkillID(123, target)
Sequential.TravelToOutpost(outpost_id)

3. Async/BottingClass (Highest Level)

# Define FSM steps using BottingClass subclass methods
bot.States.AddHeader("Travel")
bot.Move.XY(-12000, 5000)
bot.Wait.ForMapLoad(target_map_id)
bot.Move.FollowAutoPath(waypoints)
bot.States.AddHeader("Farm")
bot.Wait.UntilOutOfCombat()
bot.Move.XYAndInteractNPC(npc_x, npc_y)
bot.States.JumpToStepName("Travel")

NavMesh System

The pathfinding system is built on the game's trapezoid-based collision geometry:

  • NavMesh.find_trapezoid_id_by_coord(x, y) — locates which trapezoid contains the given coordinates
  • NavMesh.contains(x, y) — checks if point is on the navigation mesh
  • NavMesh.find_nearest_reachable(x, y) — snaps to closest walkable position
  • NavMesh.has_line_of_sight(x1, y1, x2, y2) — validates direct path
  • NavMesh.get_neighbors(trap_id) — retrieves adjacent trapezoids

FollowPath Stuck Detection

The Yield-based FollowPath includes sophisticated stuck-detection with recovery:

  • Monitors position delta over time windows
  • If stuck, attempts recovery strafing (random direction)
  • Falls back to random offset retries
  • Supports custom_pause_fn for conditional pausing (e.g., during combat)
  • Aborts on party wipe or map transition (configurable)
  • progress_callback for real-time path progress reporting

Py4GW Bot Architecture for Asterius Farm

# Conceptual Asterius Farm Bot using Py4GW BottingClass
from Py4GWCoreLib import *

class AsteriusFarmBot(BottingClass):
    def __init__(self):
        super().__init__(
            bot_name="AsteriusFarm",
            config_halt_on_death=True,
            config_pause_on_danger=False,
            config_movement_tolerance=100,
        )

    def Routine(self):
        # Step 1: Travel to Olafstead
        self.States.AddHeader("Travel")
        self.Wait.ForMapLoad(OLAFSTEAD_MAP_ID)

        # Step 2: Set Hard Mode
        # (HM = 2min patrol vs NM = 8-10min)

        # Step 3: Exit to Varajar Fells
        self.Move.XYAndExitMap(exit_x, exit_y)
        self.Wait.ForMapLoad(VARAJAR_FELLS_MAP_ID)

        # Step 4: Run to farm spot
        self.Move.FollowAutoPath(path_to_asterius_area)

        # Step 5: Buff up (Shadow Form + Sliver)
        self.States.AddCustomState(self.buff_sequence, "Buff")

        # Step 6: Engage and kill
        self.States.AddCustomState(self.combat_sequence, "Combat")

        # Step 7: Loot
        self.States.AddCustomState(self.loot_sequence, "Loot")

        # Step 8: Return to outpost
        self.Map.Travel(OLAFSTEAD_MAP_ID)

        # Loop
        self.States.JumpToStepName("Travel")
